# Пачка 07 — Визуальный слой: снимок + OCR → карта

Зависит от: 06 (захват и ввод) | Стенд: Ubuntu VM

## Цель
Последняя ступень лестницы: окно, для которого нет ни дерева a11y, ни зонда,
всё равно получает карту — текстовые блоки и кликабельные зоны с
координатами — и управляется кликами по ним.

## Прочитать
- [architecture.md](architecture.md) — «Лестница источников», «Захват пикселей».
- [contracts.md](contracts.md) §1 (`source`, `confidence`), §4, §7.
- `crates/hangui-linux/src/` — модули захвата и ввода из 06.

## Задачи
1. Крейт `crates/hangui-vision`: на вход — RGBA окна, на выход — узлы
   `source: "vision"`: `text` (строки OCR с `bounds` и `confidence`),
   `button`-кандидаты (прямоугольник с контрастной рамкой/заливкой, внутри
   — одна строка текста), `edit`-кандидаты (пустой прямоугольник светлее
   фона). Группировка в дерево по вложенности прямоугольников.
2. OCR: `ocrs` 0.13 (чистый Rust). Модели в бинарь не входят (D18):
   скачиваются при первом `vision` в `<cache>/hangui/models/` с sha256,
   вшитым в бинарь, и сообщением в stderr; `hangui fetch ocr` — заранее
   (architecture.md «Поставка», contracts.md §5). Прирост размера бинаря
   от `ocrs`/`rten`/`ureq`/`rustls` — в PROGRESS. Замерить на снимке kesl-gui (снятом через
   `XGetImage`) и gnome-calculator: доля правильно прочитанных подписей
   кнопок, время. Если < 90% подписей — стоп-и-спроси (вариант: OCR ОС).
3. `hangui tree --source vision`, `hangui screenshot`; `doctor` предлагает
   `vision`, когда остальные ступени пусты.
4. Действия над `vision`-узлом: `invoke` = клик по центру через ввод из 06
   (`via: input`), `set_value` = клик + выделить всё + ввод текста.
5. Сравнение с правдой: для kesl-gui есть карта зонда (05) — сопоставить
   прямоугольники `vision` и `probe`, процент совпадений (IoU > 0.5) в
   PROGRESS.

## Не делать
- Обучение моделей, нейросетевые детекторы элементов, распознавание иконок.
- Слежение за изменениями экрана (видео).

## Готово, когда
- `hangui tree --source vision` для окна kesl-gui без зонда показывает
  подписи «Scan», «Update», «Reports», «Settings», «View» с координатами,
  совпадающими с картой зонда (IoU > 0.5 у ≥ 80% кнопок).
- `hangui do invoke` по `vision`-узлу «View» переключает страницу (на
  Wayland — через портал из 06).

## Стоп-и-спроси
- Качество OCR недостаточно (см. п. 2).
