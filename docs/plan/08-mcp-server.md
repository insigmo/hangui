# Пачка 08 — MCP-сервер для ИИ

Зависит от: 04, 05 (06–07 желательно) | Стенд: Ubuntu VM + Claude Code как клиент

## Цель
Главная цель продукта: ИИ-агент видит карту любого приложения и управляет
им через MCP-инструменты, не зная, какая ступень лестницы сработала.

## Прочитать
- [README.md](README.md) — D7, D11.
- [architecture.md](architecture.md) — «Лестница источников».
- [contracts.md](contracts.md) §1, §4, §6, §7.
- `crates/hangui-core/src/` — трейт `Provider`, слияние, рендер.

## Задачи
1. Крейт `crates/hangui-mcp` (`rmcp` 3.8, stdio, tokio); подкоманда
   `hangui mcp`. Вызовы провайдера — через `spawn_blocking` (D6).
2. Инструменты §7. `snapshot` — текстовое дерево §5 с префиксом `[eN]`;
   для `vision`-окна — плюс PNG (image content). Таблица ссылок на сессию;
   новый `snapshot` её обнуляет.
3. Ошибки текстом с `fix`, чтобы модель исправлялась сама (`disabled`,
   `stale`, «приложению нужен `launch` с зондом»).
4. Ограничение размера: `snapshot` без `depth` у большого дерева
   обрезается на N узлов с подсказкой; N подобрать на «Параметрах» GNOME.
5. Описания инструментов — короткие, с примером селектора.
6. Тесты на `FixtureProvider`: каждый инструмент, ссылки, `stale`, `disabled`.

## Не делать
- HTTP/SSE-транспорт, авторизация, многопользовательность.

## Готово, когда
- Claude Code с `hangui mcp` (конфиг в `docs/mcp.md`) выполняет без
  подсказок: (а) «посчитай 17*23 в калькуляторе и скажи результат» (a11y);
  (б) «запусти kesl-gui и скажи, что написано в статусе Protection Center»
  (зонд). Лог вызовов — в PROGRESS.
