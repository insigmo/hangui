# Пачка 09 — TUI-инспектор

Зависит от: 03 | Стенд: Ubuntu VM (терминал в графическом сеансе) | Параллельно с 08

## Цель
Консольный аналог inspect.exe для человека.

## Прочитать
- [README.md](README.md) — D7, D12.
- [contracts.md](contracts.md) §1, §3, §5.
- `apps/hangui/src/` — разбор команд.

## Задачи
1. `hangui tui` (`ratatui` 0.30 + `crossterm`): слева дерево (раскрытие
   лениво, по Enter), справа все свойства выбранного узла + сгенерированный
   селектор (из 03).
2. Режимы: «следовать за фокусом» и «под курсором» (X11) — тумблеры
   клавишами, как в inspect.exe.
3. Поиск по селектору (`/`), обновление поддерева (`r`), копирование
   селектора в буфер (OSC 52).
4. Действие над выбранным узлом из меню (`a`): список доступных действий
   §4 с подтверждением.

## Не делать
- Подсветку элемента на экране, мышь в TUI, темы.

## Готово, когда
- На VM: открыть kesl-gui, в режиме «под курсором» навести на кнопку —
  TUI выбирает её; скопировать селектор, `hangui find` по нему находит
  ровно её. Скриншот терминала в PROGRESS.
