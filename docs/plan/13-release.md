# Пачка 13 — Сборка, CI, релиз, документация

Зависит от: 06, 10, 12 | Стенд: GitHub Actions

## Цель
Любой человек скачивает бинарь, запускает `hangui doctor` и начинает.

## Прочитать
- [README.md](README.md), [contracts.md](contracts.md) §5, §7.
- `docs/linux-matrix.md` (из 08).

## Задачи
1. CI: fmt, clippy, test на ubuntu/windows/macos; Linux-сборка без
   графического сеанса (тесты на фикстурах).
2. Релиз по тегу: бинарники linux x86_64/arm64, windows x86_64,
   macos arm64/x86_64; архивы + контрольные суммы.
3. Пользовательская документация: README (установка, `doctor`, 5 примеров
   CLI), `docs/mcp.md` (подключение к Claude Code и другим MCP-клиентам),
   `docs/selectors.md`.
4. Windows: опциональная сборка с `uiAccess` и инструкция по подписи;
   macOS: подпись и нотаризация, если владелец даст сертификаты.

## Не делать
- Пакеты для дистрибутивов (deb/rpm/brew) — после первого релиза.

## Готово, когда
- Тег `v0.1.0` даёт релиз со всеми бинарниками; скачанный бинарь на чистой
  Ubuntu VM проходит `doctor` и `tree` для kesl-gui.

## Стоп-и-спроси
- Сертификаты подписи, публикация релиза — только с явного согласия владельца.
