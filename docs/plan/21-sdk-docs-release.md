# Пачка 21 — Руководство для ИИ, примеры, публикация SDK

Зависит от: 15, 17, 18, 19, 20 | Стенд: Ubuntu VM + Claude Code; CI

## Цель
ИИ-агент без подсказок пишет на любом из четырёх языков тест, который
проходит повторно без ИИ; пакеты ставятся из PyPI, Go proxy, npm, NuGet.

## Прочитать
- [README.md](README.md) — D14–D19.
- [contracts.md](contracts.md) §3, §10, §11.
- `sdk/*/README.md`, `docs/mcp.md` (из 15).

## Задачи
1. `docs/testing.md` — руководство «как ИИ пишет тест на hangui»:
   исследовать приложение через MCP (`snapshot`, `selector_for`) →
   переносить **селекторы**, не ссылки `eN` → действие с автоожиданием →
   проверка через `wait`/`inspect`; что делает тест устойчивым (`id` вместо
   `:nth`, без `sleep`, без координат, `vision` только с проверкой
   `confidence`); одна и та же проверка на четырёх языках.
2. `llms.txt` в корне и короткий раздел в каждом `sdk/*/README.md`
   (установка, запуск сервера, пять строк теста, таблица ошибок) — чтобы
   ИИ, которому дали только пакет, нашёл, как им пользоваться.
3. Примеры `examples/<язык>/` на двух целях: gnome-calculator (a11y) и
   kesl-gui (зонд), один и тот же сценарий на всех языках.
4. Версии: SDK и бинарь выпускаются одной версией; SDK проверяет
   `protocol` (§10.3 `health`) и говорит, какую версию hangui поставить.
5. Публикация по тегу (расширение CI из 15): PyPI (trusted publishing),
   npm (provenance), NuGet, тег `sdk/go/vX.Y.Z`; каждый шаг — только с
   согласия владельца.
6. Сборка пакетов SDK вшивает таблицу sha256 из `dist/checksums.json`
   того же релиза (§11.6); CI проверяет, что версия пакета = версия
   бинарей, а адреса `.gz` из таблицы отвечают 200. Бинаря внутри пакетов
   нет — его скачивает сам SDK (D19); `docs/testing.md` и README SDK
   описывают `HANGUI_BIN`, `HANGUI_DOWNLOAD=0`, `HANGUI_DOWNLOAD_URL` и
   предзагрузку для CI без сети.

## Не делать
- Генератор тестов, запись действий в тест (README «Не делать»): тест
  пишет ИИ, hangui даёт ему MCP для исследования и SDK для кода.

## Готово, когда
- Claude Code с MCP hangui и только `docs/testing.md` в контексте пишет
  на каждом из четырёх языков тест «нажать View в kesl-gui и проверить
  заголовок страницы»; каждый тест затем проходит 3 запуска подряд без ИИ
  (лог в PROGRESS).
- Пакеты установлены из реестров на чистой VM, примеры проходят.
