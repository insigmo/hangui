- **A.** Первая цель Linux — приложения с мостом (GNOME/GTK, Qt системный); kesl-gui — пример «нет дерева», `doctor` это объясняет. Пачки 02–05 меняют эталон на gnome-calculator/Settings/Files.

- **C.** Попытка подменить kesl-gui его Qt на системный 5.15 (через `LD_PRELOAD`, т.к. у бинаря `DT_RPATH`). Нужен `sudo apt install` Qt5-пакетов владельцем; хрупко и только для kesl-gui.
